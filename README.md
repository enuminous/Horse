**Human–Operational Recursive System Evaluation**

HORSE is an experimental EFMW-inspired framework for evaluating the coupled human–machine operational loop rather than treating the human and the system as isolated components.

## Core question

> Does the human–system pair remain calibrated, understandable, and operationally effective as state, workload, uncertainty, and responsibility change over time?

HORSE evaluates joint performance, handoff quality, trust calibration, intervention timing, and workload distribution.

## Primary outputs

- joint task effectiveness
- trust calibration
- override quality
- handoff integrity
- workload balance
- human-state divergence
- intervention latency
- recursive team coherence
